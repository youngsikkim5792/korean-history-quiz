# 한국 역사 퀴즈 게임

Python으로 만든 콘솔 기반 한국 역사 퀴즈 게임입니다.

## 주요 기능
- 한국 역사 기본 문제 5개 제공
- 객관식 퀴즈 풀이
- 정답 및 오답 확인
- 문제당 20점 점수 계산
- 사용자 퀴즈 추가
- 퀴즈 목록 확인
- JSON 파일 자동 저장
- 최고 점수 저장 및 조회
- 잘못된 메뉴 입력 처리

## 실행 방법

Python 3 설치 후 터미널에서 실행합니다.

```powershell
py main.py
```

## 메뉴
1. 퀴즈 풀기
2. 퀴즈 추가하기
3. 퀴즈 목록 보기
4. 최고 점수 확인
5. 종료

## 프로젝트 구조

- main.py : 메인 메뉴 및 퀴즈 추가
- quiz.py : 퀴즈 클래스
- questions.py : 기본 한국 역사 문제
- quiz_game.py : 게임 진행, 점수 및 저장
- state.json : 추가 문제와 최고 점수 저장
